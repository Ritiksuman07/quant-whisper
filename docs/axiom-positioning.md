# Axiom Positioning

QuantFlow is positioned as the open-source foundational research engine for **Axiom Algos**.

## Why this framing matters

- It signals that QuantFlow is not a toy script but a production-bound architecture.
- It creates continuity from OSS experimentation to managed commercial workflows.
- It gives contributors a clear roadmap and context for technical decisions.

## Open Core -> Commercial Path

1. **Open Source Core (Now)**  
   Agentic ingestion, strategy synthesis, deterministic backtest, and reproducible run artifacts.
2. **Managed Cloud (Next)**  
   Hosted execution, shared data caches, run history analytics, and team collaboration primitives.
3. **Strategy Registry / Marketplace (Later)**  
   Audited strategy packages, discoverability, and permissioned monetization workflows.

## Messaging Guidelines

- Lead with reproducibility and deterministic research.
- Show visual proof quickly (TUI + run artifacts).
- Be explicit that outputs are research artifacts, not investment advice.
- Keep startup narrative grounded in shipped OSS capabilities.
