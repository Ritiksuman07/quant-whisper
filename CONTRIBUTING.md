# Contributing

Thanks for your interest in contributing to portman.

## Getting Started

- Fork the repo and create your branch from `master`.
- Install Go 1.22+.
- Run `go test ./...` and `go build ./...` before submitting.

## Commit Messages

Use clear, descriptive commit messages (e.g., "Fix scanner refresh race").

## Pull Requests

- Keep changes focused and small when possible.
- Include screenshots or GIFs for UI changes.
- Describe the problem, solution, and any tradeoffs.

## Code Style

- Follow standard Go formatting (`gofmt`).
- Keep error messages user-friendly.
- Avoid breaking keybindings without discussion.

## Reporting Issues

Please include:

- OS and terminal
- Steps to reproduce
- Expected vs. actual behavior
- Logs or screenshots, if helpful
